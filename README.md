## 本地静态预览

在仓库根目录启动静态文件服务：

```bash
python3 -m http.server 8765
```

浏览器打开 http://127.0.0.1:8765/ 。请从站点根目录提供文件，使 `/assets/`、`/sw.js` 与 `/manifest.json` 的路径和线上一致。

## 乘法百数板

打开页面后，点右下角「✖️ 乘法百数板」。

- 分组：行是组数，列是每组个数。点一格后，右侧显示算式，并用圆点按组展示。
- 交换：两个因数不同时，可点「看看 a×b」交换因数，乘积不变。
- 练习：切换到「练习」后，格内乘积会被遮住。可以填写答案、检查，或点「看分组提示」。

百数板进度写在本机浏览器的 `anna_multiplication_chart_v1`。原消消乐仍由页面中的 `#root` 加载上述已构建脚本。
