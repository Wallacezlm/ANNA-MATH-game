# 数学消消乐

这是可直接部署的静态发布版本。页面从仓库根目录的 `index.html` 进入。`assets/` 里的 JS 与 CSS 是已经构建好的产物，里面包含原来的 React 消消乐。本仓库没有原始 React 组件源码。乘法百数板写在 `index.html` 里。

访客看到的游戏名是「数学消消乐」。GitHub 仓库名和 Netlify 项目域名没有改。错题、学习记录仍使用原来的 `anna_math_*` 本地存储键，百数板模式仍使用 `anna_multiplication_chart_v1`。备份文件里的内部 `appName` 仍是 `ANNA Math Match`，这样已有备份可以继续导入。这些技术名称不会显示在标题、页眉或安装名称上。

## 本地静态预览

在仓库根目录执行：

```bash
python3 -m http.server 8765
```

浏览器打开 http://127.0.0.1:8765/ 。请从站点根目录提供文件，使 `/assets/`、`/sw.js` 与 `/manifest.json` 的路径和线上一致。

## 乘法百数板

打开页面后，点右下角「✖️ 乘法百数板」。

约定是 **a×b 表示 b 组、每组 a 个**。行是每组个数，列是组数。

- 例如 5×3：3 组，每组 5 个，重复加法是 5＋5＋5＝15。
- 交换成 3×5：5 组，每组 3 个，重复加法是 3＋3＋3＋3＋3＝15。
- 练习会遮住乘积。答对后的反馈、分组提示和圆点数量使用同一约定。
